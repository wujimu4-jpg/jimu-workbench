# 积木工作台

一个可以实际操作的中文内容编导工作台原型。无需注册应用账号或配置 AI 密钥，四位虚构达人与七条示例视频首次打开时自动创建。

## 开始体验

公开体验地址：[积木工作台](https://wujimu4-jpg.github.io/jimu-workbench/)。无需登录，打开即可体验。

当前版本的数据与后台截图保存在每位使用者自己的浏览器中，不会自动共享给其他访问者。若从旧地址迁移，请在旧页面的「设置」导出备份，再在新地址导入。

本地运行：安装 Node.js 20 或更新版本，在本目录运行 `npm start`，浏览器打开 `http://127.0.0.1:4178`。没有额外依赖需要安装。请使用在线地址或本地服务体验完整功能；直接双击 HTML 文件时，浏览器可能限制图片存储和文字识别。

首页点击 **体验完整制作流程**，会打开或继续演示项目，不会清空进度。

1. 编辑标题与切入角度，点击“我确认选题，进入脚本”。
2. 生成模拟脚本与拍摄方案，修改后确认。
3. 可选填写品牌 Brief，添加达人待确认事项；全部勾选后进入拍摄。此处不会自动发送消息。
4. 将拍摄状态设为“已完成”，确认素材齐备。
5. 输入剪辑结果，提交审核；可退回修改、再次提交，最后由编导审核通过。
6. 登记发布平台与时间。可以点击“填入演示数据”，再保存进入复盘；真实数据请填入一致的 24h / 3天 / 7天统计窗口和来源。
7. 生成单条复盘。逐条采纳、修改或拒绝建议；填写最终方向、确认人，并亲自勾选确认。
8. 点击“按确认方向创建下一条策划”。下一条保持待确认状态，与本次复盘双向关联。
9. 周会中心引用已经人工确认的方向，可导出纯文本提纲。

## 视频分析（新增）

左侧「视频分析」汇总已发布视频，也可从视频项目里的「分析这条视频」进入。

- 发布后可先点击「先登记发布，开始视频分析」，无需等待统计窗口结束；之后再补录数据。
- 关联本地成片进行播放，读取时长与画面尺寸。视频只在浏览器中读取，不上传。刷新后需重新选择视频文件；文件名、元信息、内容观察和分析报告会保留。
- 从开头、叙事、口播、画面声音、剪辑节奏、结尾、品牌融合七个维度记录具体观察，标注可保留或待调整。可填入明确标注的示例观察体验。
- 可手动粘贴成片逐字稿、评论，以及前5秒留存、2秒跳出、平均观看时长，补充指标需注明来源和窗口。
- 生成规则模拟报告：区分观察依据、待验证判断与数据事实。不会自动识别画面、转写音频，缺失项不会自动打分；内容分析不会直接证明播放表现的原因。
- 报告可导出；带入复盘时仍需编导逐条确认，替换已有未确认建议会提示。已确认方向不被改写。修改材料或数据后旧报告标记为待更新。
- 备份包含观察、元信息和报告，不包含本地视频文件本身。

## 其他入口

- 达人管理：新增、修改人物档案、暂停、移交、归档、恢复；不直接删除达人。移交保留交接说明及历史视频，属于本地业务记录，不会邀请真实同事。
- 选题策划 → 热点雷达：抖音 / 小红书，1天 / 3天 / 7天、赛道与关键词筛选；收藏、手动链接录入、转选题。收藏默认保留全部时间的记录。
- 商务合作 → 商业热点雷达：独立商业灵感列表；转选题必须对应品牌与需求。
- 文案工作室 / 制作中心 / 数据复盘：集中打开同一视频项目的当前进度。
- 设置：导出 JSON 备份、校验并确认导入、修改默认确认人、确认后恢复演示数据。

## 后台截图录入（新增）

进入视频项目的「发布与数据」，或在复盘页点击「修改录入数据」。

1. 保留作品链接，选择平台、统计窗口和采集时间。当前未接入达人账号授权，不能仅凭视频链接读取抖音、小红书的完整后台数据。
2. 上传、拖入或直接粘贴后台截图。支持 PNG / JPG / WebP；每条视频最多 8 张，每张不超过 8 MB，当前浏览器截图总量不超过 32 MB。
3. 点击缩略图放大对照填写；也可点击「识别数据」，使用浏览器本地中文文字识别。首次启动需要加载识别资源，图片不会发送到识别服务。
4. 对照原图核对候选值，勾选需要填入的字段，并确认视频归属与统计窗口。没有识别出的字段、存在冲突的数值不会猜测补全；万 / 千单位会提示为近似换算。可修正识别文字或候选值。
5. 点击「确认填入所选字段」，结果先保存为草稿；再保存录入数据，才会更新正式复盘数据。识别不会自动覆盖原数据。

截图与录入草稿在刷新后保留。复盘页可以查看原始截图依据。「设置 → 导出备份」包含截图原图，可在另一浏览器导入恢复；最大导入文件 48 MB。移除截图不会删除已录入的数字。截图上传时间不等于后台数据采集时间，统计窗口仍需人工确认。

本地文字识别为实际 OCR，不是模拟生成；复杂多列排版、压缩图片和小字可能识别不准，保留人工核对步骤。采用随站点提供的 Tesseract.js 6.0.1 和中英文识别资源，约 21 MB，点击识别时才加载。版本、来源与许可证见 `dist/vendor/ocr/SOURCES.txt` 及同目录许可证文件。

平台数据自动接入需要独立的授权服务。例如，抖音官方视频基础数据接口要求权限申请与用户授权，具体限制见[官方文档](https://open.douyin.com/platform/resource/docs/openapi/data-open-service/video-data/get-basic-data/)。本版本没有宣称已接入任何平台后台。

## 数据和服务边界

- 当前为个人试用原型，业务记录保存在当前浏览器与当前网址的 LocalStorage 中，截图原图保存在 IndexedDB 中。刷新会保留，不同设备、不同浏览器、在线地址与本地地址之间不共享。请定期导出包含图片的备份；清除浏览器数据会删除记录和截图。
- 热点没有接入平台授权接口。所有记录明确区分“示例数据”和“手动录入”；保存链接不会抓取或核验内容。没有伪造实时热度、涨幅或原视频链接。
- 脚本和复盘采用本地规则模拟，没有真实模型调用。对比范围限定同达人、同平台、同统计窗口、早于本条发布的视频；计算历史中位数，不从播放量推断收入或转化，不声称发现因果。
- 本原型登记拍摄、剪辑与发布进度，仅支持本地成片预览，不上传、转码、剪辑视频，也不自动发布到抖音 / 小红书。
- 方向确认属于界面与状态机业务门槛，不是多用户身份认证。所有业务角色由当前试用者操作；正式团队使用需接入身份权限、审计与数据库。

## 工程结构与后续接入

- `dist/index.html`：入口；`style.css`：响应式视觉；`app.js`：页面、表单、持久化与交互。
- `dist/analysis-core.js` / `analysis.js`：视频内容分析、材料预览、模拟报告与复盘衔接。
- `dist/evidence-core.js` / `evidence.js`：截图存储、数据草稿、本地文字识别、人工核对与原图备份；`dist/vendor/ocr/` 为本地识别资源。
- `dist/core.js`：独立业务逻辑，包括状态机、数据校验、同口径复盘、模拟脚本和下一条关联。
- `server.cjs`：零依赖本地静态服务。
- `tests/core.test.cjs`：业务约束测试；`tests/ui.test.cjs`：真实浏览器端到端验证。

将 `mockScript(project, creator)` 与 `review(project, projects)` 替换为服务端生成适配器即可扩展真实 AI。服务端必须保管密钥、返回带来源与生成模式的可编辑草稿；客户端保留现有人工确认状态机，AI 不得自行确认最终方向。热点接入建议保留 `platform/source/publishedAt/collectedAt/url` 字段，并为授权来源持续存储快照；不要将当前热榜等同于过去 7 天。

本地业务测试：`npm test`。
浏览器测试需要 Playwright 和 Chrome：`PLAYWRIGHT_MODULE=/absolute/path/to/playwright node tests/ui.test.cjs`（先启动本地服务）。测试使用隔离的浏览器上下文，不更改用户当前浏览器中的数据。

专项浏览器检查为 `tests/analysis-ui.test.cjs` 和 `tests/evidence-ui.test.cjs`；使用相同的 Playwright 环境变量运行。截图检查实际启动中文 OCR，并验证确认前数据保持不变、刷新保留及跨浏览器上下文的原图备份恢复。

## GitHub Pages 发布

本仓库通过 `.github/workflows/pages.yml` 发布 `dist/`。推送到 `main` 后，先运行业务测试，再自动更新公开网页。仓库 Settings → Pages 使用 GitHub Actions 作为发布来源。
